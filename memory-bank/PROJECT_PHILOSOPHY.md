# Project Philosophy

TotoAI is a research and package-generation project for BaltBet toto.

Principles:
- Do not claim guaranteed profit.
- Optimize probability and expected value under a user-defined budget.
- Keep stake configurable; the default BaltBet coupon stake is 30 RUB.
- Separate prediction quality from cover/package quality.
- Treat every betting hypothesis as unproven until it is backtested.
- Prefer reproducible SQLite-based research over ad hoc conclusions.
- Keep project knowledge inside this repository.
