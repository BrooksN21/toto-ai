# Pinnacle

Pinnacle is not integrated in the current repository.

Current relevant code:
- `study-bk` compares TotoBrief `bk_*` probabilities with `norm_*` odds-derived
  probabilities.
- `calibration` evaluates how stored bookmaker probabilities match results.

Future use may include external odds comparison, but no API client, storage
table, or collector exists for Pinnacle yet.
