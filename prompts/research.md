# Research Prompt

Use this prompt shape for TotoAI research tasks.

```text
Create research study: <name>

Goal:
- <hypothesis or measurement>

Data:
- Use collected SQLite data from TotoBrief.
- Exclude missing or unsupported results where required.

Output:
- Rich CLI summary.
- CSV report.
- Markdown report.
- Tests.
- Updated project knowledge.
```
